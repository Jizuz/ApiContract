## 能力概述
为契约网关的关键策略（元数据发布、调用器生成、序列化、路由、负载均衡、容错、限流、过滤器等）提供统一 SPI 扩展机制：框架提供内置实现，业务可实现并覆盖任意策略，且每个策略可通过配置项切换；面向框架开发与业务定制角色。

## 业务前置条件
- 扩展点接口已声明默认实现名称
- 业务实现按统一规范注册（声明式，无侵入主流程）
- 每个扩展点有对应配置项，默认值即内置默认实现

## 输入定义
| 名称 | 类型 | 是否必填 | 说明 |
| ---- | ---- | -------- | ---- |
| 扩展实现 | 业务提供的策略实现 | 否 | 按扩展点接口实现并声明注册 |
| 策略选择配置 | 配置项 | 否 | 未配置时使用内置默认实现 |

## 输出定义
| 名称 | 类型 | 说明 |
| ---- | ---- | ---- |
| 生效的策略实例 | 单例 | 按扩展点维度缓存，统一按名称获取 |
| 覆盖提示日志 | 启动日志 | 明确提示哪个内置实现被业务实现覆盖 |

## 主流程（正向链路）
1. 启动时统一加载器按扩展点维度加载全部实现并缓存单例。
2. 按配置项或业务声明确定生效实现；业务实现优先于框架内置实现。
3. 启动日志输出被覆盖的扩展点清单。
4. 运行期主流程经统一入口调用当前生效实现。

## 分支场景
- 扩展点清单（13 个）与内置实现：

| 扩展点 | 所属端 | 职责 | 内置实现 |
| ---- | ---- | ---- | ---- |
| 契约元数据发布器 | Provider | 元数据发布方式 | 配置中心模式 / 实例元数据模式 / 仅日志模式 |
| 调用器生成器 | Provider | 调用器生成方式 | 字节码 / 反射 |
| 参数转换器 | Provider | 参数类型转换 | 默认转换实现 |
| 参数校验器 | Provider | 参数校验 | 标准校验实现（可关闭） |
| 导出过滤器 | Provider | 白名单二次过滤（环境、租户） | 无（默认放行） |
| 序列化器 | 双向 | 编解码 | json / protobuf |
| 路由器 | 网关 | 实例过滤 | 版本路由、标签路由（链式） |
| 负载均衡器 | 网关 | 选实例 | 轮询 / 随机 / 一致性哈希 / 加权 |
| 集群策略 | 网关 | 失败重试与换实例 | failover / failfast / failsafe |
| 限流器 | 网关 | 契约级限流 | 令牌桶 / 漏桶 |
| 调用过滤器 | 网关 | 调用前后拦截 | trace、日志、指标（鉴权本期不提供内置实现，仅预留扩展点） |
| 参数提取器 | 网关 | 从请求提取参数数组 | query / jsonBody / protobufBody |
| 熔断器 | 网关 | 熔断判定 | 失败率熔断 |

## 异常场景 & 业务错误码
| 场景 | 错误码 | 业务表现 |
| ---- | ------ | -------- |
| 配置指定的实现名不存在 | SPI_IMPL_NOT_FOUND | 启动失败并明确指明扩展点与名称 |
| 实现加载或初始化失败 | SPI_LOAD_FAILED | 启动失败，不静默回退到错误状态 |
| 业务实现运行期异常 | 按所处链路错误码 | 异常不吞没，按所处环节收敛为对应错误码 |

## 数据约束
- SPI 只用于策略与插件；主流程（白名单加载、注解解析、寻址链路）不拆 SPI
- 实现按扩展点维度单例缓存，随应用生命周期
- 内置实现全部可被业务实现覆盖

## 权限与数据隔离
- 业务侧实现可覆盖框架内置实现，启动日志提示被覆盖项
- 覆盖行为对同端全局生效（按端隔离：Provider 端 / 网关端扩展点互不混用）

## 并发与重试规则
- 加载期为一次性动作，运行期不再动态加载
- 策略实现需自行保证线程安全

## 业务容量约束
- 无业务容量限制（纯机制能力）

## 验收用例（测试要点）
✅ 正向用例
- 业务实现覆盖内置实现后生效，且启动日志提示覆盖项
- 每个扩展点的配置项切换内置实现（如 轮询→随机、json→protobuf、字节码→反射）即时生效
- 13 个扩展点均可独立扩展，互不影响

🔄 边界用例
- 不提供业务实现时全部使用内置默认值
- 导出过滤器默认放行，配置后按环境/租户二次过滤

❌ 异常用例
- 配置指向不存在的实现名：启动失败并指明扩展点
- 实现初始化失败：启动失败不静默
- 运行期实现异常按所处链路收敛错误码，不吞没

## 兼容与灰度规则
- 通过配置项组合实现灰度（如发布方式回退、调用器回退、序列化切换）
- 新增内置实现不破坏既有业务扩展

## 业务埋点与告警指标
- 启动期输出扩展点加载与覆盖清单
- 扩展实现运行异常计数

## 规格备注
- 本能力是其余能力"可降级、可灰度"的机制基础
- 鉴权过滤器本期仅预留扩展点、不提供内置实现（已确认决策）
