## 能力概述
Provider 为每个已导出契约在启动期生成调用器，并通过统一泛化入口对外服务：按契约标识分发请求、完成参数转换与校验、执行目标方法、收敛异常与错误码；面向网关（唯一合法调用方）角色。

## 业务前置条件
- 契约已通过白名单与注解扫描（依赖 `contract-definition`）
- 契约元数据已成功发布（依赖 `contract-metadata` 的顺序不变量）
- 统一泛化入口路径可配置，且不与业务路径冲突
- 泛化入口仅限内网访问（本期不做鉴权，依赖内网访问限制）

## 输入定义
| 名称 | 类型 | 是否必填 | 说明 |
| ---- | ---- | -------- | ---- |
| 契约标识 | 查询参数 | 是 | 指明要调用的契约 |
| 参数数组 | 请求体 | 是 | 按契约参数名与类型顺序编码；无参契约为空数组，忽略请求体 |

## 输出定义
| 名称 | 类型 | 说明 |
| ---- | ---- | ---- |
| 调用结果 | 编码内容 | 按契约返回类型与契约声明的序列化方式编码 |
| 统一错误结构 | 结构化数据 | 错误码、可对外消息、traceId；不包含内部堆栈 |
| 契约调用日志 | 本地日志 | 完整堆栈仅写本地日志并关联 traceId |

## 主流程（正向链路）
1. 统一入口接收调用请求，解析契约标识。
2. 查询本地调用器缓存：命中则继续；未命中直接返回契约不存在，不进入任何兜底调用。
3. 按契约序列化方式将请求体反序列化为参数对象。
4. 完成类型转换（基础类型、集合、DTO；日期、枚举、金额统一规则）。
5. 校验参数个数必须等于契约参数个数；可选执行业务校验。
6. 调用器执行目标方法（启动期生成，运行期不经反射，不生成新调用器）。
7. 结果按契约方式序列化返回；目标方法抛出异常时剥离包装取真实异常并转为调用异常错误码。

## 分支场景
- 无参契约：参数数组为空，忽略请求体
- 调用器生成失败：单个契约降级为备用调用方式或标记该契约不可用，不影响其他契约
- 字节码调用模式可整体切换回反射模式（用于排障）
- 空参数值保持 null，不做默认值填充

## 异常场景 & 业务错误码
| 场景 | 错误码 | 业务表现 |
| ---- | ------ | -------- |
| 契约不存在（未导出、未标注或未注册） | CONTRACT_NOT_FOUND | 明确错误码返回，不进入任何兜底 |
| 参数非法（个数、类型、校验失败） | CONTRACT_ARGUMENT_INVALID | 返回参数错误，指明原因 |
| 调用异常（目标方法抛出业务异常） | CONTRACT_INVOKE_ERROR | 剥离代理/反射包装后取真实异常；仅返回错误码与消息 |
| 框架级内部异常（序列化、转换失败） | CONTRACT_INTERNAL_ERROR | 框架异常与业务异常区分，便于网关判断是否重试 |

## 数据约束
- 调用器常驻内存，随应用生命周期；运行期不生成新调用器
- 一个契约唯一绑定一个签名（禁止重载）
- 参数个数不符直接拒绝，不发起目标方法调用
- 完整堆栈只写本地日志并关联 traceId；错误响应不含内部堆栈

## 权限与数据隔离
- 泛化入口限制内网访问；本期不做鉴权（契约级鉴权预留过滤器扩展点，本期不实现）
- 入口可调用本应用全部导出契约，防护依赖内网限制与契约级限流

## 并发与重试规则
- 泛化入口本身不引入重试，重试由网关集群策略统一控制
- 契约方法实现方需自行保证幂等（写类契约在重试场景下可能被多次调用）

## 业务容量约束
- 请求体大小设上限，超限返回参数错误
- 单契约参数建议不超过 10 个

## 验收用例（测试要点）
✅ 正向用例
- 各类型参数（基础类型、DTO、集合、日期、枚举、金额）转换正确并成功调用
- 调用结果按契约序列化方式正确编码返回
- 业务异常返回 CONTRACT_INVOKE_ERROR 且 traceId 可关联本地完整堆栈日志

🔄 边界用例
- 无参契约忽略请求体正常调用
- 单契约调用器生成失败降级备用方式，其他契约不受影响
- null 参数保持 null 透传

❌ 异常用例
- 未导出/未注册契约返回 CONTRACT_NOT_FOUND，无兜底调用
- 参数个数不符、类型转换失败返回 CONTRACT_ARGUMENT_INVALID
- 框架级异常返回 CONTRACT_INTERNAL_ERROR，与业务异常可区分
- 错误响应不含内部堆栈

## 兼容与灰度规则
- 调用器生成方式（字节码/反射）可配置切换，用于灰度与排障回退
- 转换与校验规则可通过扩展点替换

## 业务埋点与告警指标
- 调用器生成结果日志（逐契约记录生成方式）
- 契约级调用日志（成功/失败、耗时）
- 契约级失败率告警

## 规格备注
- 与 `contract-definition`（什么能导出）、`contract-metadata`（发布顺序）、`contract-serialization`（编码方式）强关联
- 泛化入口路径默认 `/_contract/rpc`，可配置避让业务路径
