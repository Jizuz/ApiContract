- 单机 loopback 压测：client 与 server 共享 macOS 临时端口池（~16k），基线组每请求断连的 TIME_WAIT（30s）构成端口预算约束，故采用短段 + 32s 段间冷却；生产环境 client/server 分离、server 侧固定监听端口，无此约束。
- 绝对 QPS 为本机开发环境量级（同 JVM 交替对照消除环境差异，验收口径为两组**比值** ≥ 1.5×，非绝对值）。
