## 能力概述
网关以前端传入的契约标识（mt）为唯一寻址键，完成契约查找、实例发现、路由过滤、负载均衡与失败容错，前端全程不感知服务名、接口路径与实例地址；面向前端/中台调用方角色。

## 业务前置条件
- 网关本地契约索引已就绪（订阅契约元数据，依赖 `contract-metadata`）
- 实例列表订阅正常，或处于单机调试模式（直连本地实例）
- 调用链顺序固定：**路由 → 限流 → 负载均衡 → 调用 → 容错**，顺序不可配置打乱（避免限流失效或重试绕过路由）
- 默认部署形态为独立网关集群；本地开发与联调可用单机调试模式

## 输入定义
| 名称 | 类型 | 是否必填 | 说明 |
| ---- | ---- | -------- | ---- |
| mt | 查询参数 | 是 | 契约标识，网关唯一寻址键；缺失或为空返回参数错误 |
| 业务参数 | 查询串/请求体 | 按契约 | GET 按参数名从查询串取首值，缺省为 null；POST 按参数名从对象取值或直接为参数数组 |
| 请求版本 | 查询参数 | 否 | 指定契约版本路由，缺省用默认版本 |
| Content-Type | 请求头 | 否 | 前端↔网关固定 JSON（已确认决策：前端不解析二进制） |

## 输出定义
| 名称 | 类型 | 说明 |
| ---- | ---- | ---- |
| 契约结果 | JSON 内容 | 成功返回契约结果（前端侧恒为 JSON） |
| 统一错误结构 | 结构化数据 | `code / message / traceId / data`；不含内部堆栈 |

## 主流程（正向链路）
1. 解析 mt（缺失 → 400）。
2. 契约主索引查询（未命中 → 404）。
3. 按元数据服务名取候选实例列表（空 → 503）。
4. 路由链按版本、标签、灰度规则过滤实例。
5. 契约级限流判定（拒绝 → 429）。
6. 负载均衡策略选出目标实例。
7. 按元数据参数名提取并组装参数数组（个数不符直接返回参数错误，不发起远程调用）。
8. 过滤器链前置处理（traceId、日志；鉴权过滤器本期不做、仅预留扩展点）。
9. 经连接池异步发起调用（请求体按契约声明的序列化方式编码）。
10. 集群策略处理失败（重试 / 换实例 / 直接失败）。
11. 过滤器链后置处理、异常收敛。
12. 返回结果（mt 仅用于网关寻址，不透传给 Provider）。

## 分支场景
- GET 与 POST 两种参数提取形态；无参契约忽略请求体
- 版本路由：请求指定版本或按默认版本选取
- 标签路由：gray、canary 等实例标签过滤（灰度规则）
- 单机调试模式：关闭注册中心发布，网关直连本地实例
- 实例列表为空的结果短时缓存（默认 1 秒），防止击穿

## 异常场景 & 业务错误码
| 场景 | 错误码 | 业务表现 |
| ---- | ------ | -------- |
| mt 缺失或为空 | MT_MISSING | 400 |
| 索引无该契约 | CONTRACT_NOT_FOUND | 404（未导出、未标注或未注册） |
| 参数个数或类型不符 | ARGUMENT_INVALID | 400，不发起远程调用 |
| 契约存在但无健康实例 | NO_INSTANCE | 503 |
| 契约级限流拒绝 | RATE_LIMITED | 429 |
| 请求体编解码失败 | SERIALIZE_ERROR | 400 |
| Provider 返回业务异常 | INVOKE_ERROR | 502 |
| 熔断打开 | CIRCUIT_OPEN | 503 |
| 调用超时 | TIMEOUT | 504 |
| 连接失败、连接池耗尽 | UPSTREAM_UNAVAILABLE | 503 |

## 数据约束
- 空实例结果短时缓存防击穿；实例刷新失败沿用最近一次快照，不清空
- 契约与实例分开缓存；契约靠推送刷新，实例靠推送 + 兜底定时校准
- 参数个数不符在网关侧拦截，不发起远程调用

## 权限与数据隔离
- 本期不做网关鉴权与契约级授权（已确认决策），仅在过滤器链预留扩展点
- 契约级限流防止单个契约拖垮整体

## 并发与重试规则
- 失败重试由集群策略统一控制（failover 换实例重试 / failfast 快速失败 / failsafe 安全失败），默认重试次数可配（默认 2）
- 重试仅针对框架级异常；业务异常不重试

## 业务容量约束
- 网关单机 QPS 目标：优化后不低于基线 1.5 倍
- 网关 P99 在契约级超时内完成，超时率低于 0.1%
- 请求体大小设上限，超限返回参数错误
- 契约条目按业务规模设上限并监控

## 验收用例（测试要点）
✅ 正向用例
- 新增契约仅需接口、白名单、实现类三步，网关零配置即可调用成功
- GET/POST 各参数形态正确提取组装；版本/标签路由命中正确实例
- traceId 经过滤器链透传至 Provider，两侧日志可关联

🔄 边界用例
- 无参契约忽略请求体；GET 缺省参数取 null
- 空实例结果 1 秒缓存防击穿；实例刷新失败沿用快照
- 单机调试模式直连本地实例调用成功

❌ 异常用例
- 十类错误码分别在对应场景正确触发（缺失/未命中/无实例/参数/限流/编解码/业务异常/熔断/超时/上游不可用）
- 参数个数不符不发起远程调用
- 重试不绕过路由链

## 兼容与灰度规则
- 默认负载均衡为轮询，可切换随机、一致性哈希、加权
- 路由链按版本、标签灰度放量；顺序固定不可打乱
- 前端接入零改造：仅需拼接 `?mt={契约标识}` 并携带参数

## 业务埋点与告警指标
- 契约维度 QPS、RT、错误率、重试次数
- 限流拒绝量、熔断次数
- 索引刷新（配置推送至生效耗时，秒级）
- 告警：索引刷新失败、熔断打开、连接池耗尽

## 规格备注
- 本能力是前端唯一入口；与 `contract-metadata`（索引来源）、`contract-async-stability`（调用执行）、`contract-serialization`（编码）关联
- 错误结构统一为 `code / message / traceId / data`
