## 能力概述
契约元数据以配置中心为唯一权威存储，按服务维度一份、全实例共享；Provider 必须先发布契约元数据、后注册实例，网关订阅配置构建本地索引，实现契约变更与实例上下线互不干扰；面向后端开发者与网关运维角色。

## 业务前置条件
- Provider 已完成契约扫描并生成契约集合（依赖 `contract-definition`）
- 启动期强依赖配置中心可用；实例注册依赖注册中心可用
- 网关与 Provider 依赖同一版本的契约定义模块
- 实例元数据仅保留版本、契约数量等极简标记，不携带契约明细

## 输入定义
| 名称 | 类型 | 是否必填 | 说明 |
| ---- | ---- | -------- | ---- |
| 服务契约集合 | 结构化内容 | 是 | 服务名、版本、契约条目列表及聚合索引 |
| 配置变更推送 | 事件 | 是 | 配置中心在契约变更后主动推送 |
| 实例列表变更 | 事件 | 是 | 注册中心在实例上下线时推送 |

## 输出定义
| 名称 | 类型 | 说明 |
| ---- | ---- | ---- |
| 服务契约配置 | 配置中心条目 | 一个服务一份；含契约集合与聚合索引，支持快速判重 |
| 网关本地三级索引 | 内存索引 | 契约主索引（mt→契约条目）、服务索引（服务→契约标识集合）、版本索引（mt+版本→契约条目） |
| 实例极简标记 | 实例元数据 | 契约版本、契约数量等少量键值 |
| 发布自检日志 | 结构化日志 | `meta published` / `registry joined` 记录 |

## 主流程（正向链路）
### Provider 发布侧
1. 扫描生成契约集合与调用器。
2. 通过聚合索引完成契约标识全局唯一性校验、同标识同版本签名兼容性校验。
3. 发布契约元数据到配置中心，覆盖写入本服务对应配置条目。
4. 发布成功后注册实例并写入极简标记。
5. 任一步失败则中断启动，禁止出现"实例已上线但契约缺失"的中间态。

### 网关订阅侧
1. 启动时订阅全部契约配置，一次性构建三级本地索引。
2. 配置推送到达：解析变更内容，原子替换该服务相关条目，清理已被删除的契约。
3. 实例变更推送：只更新地址列表，不触发契约解析。
4. 契约与实例双索引分离，互不引起全量刷新。

## 分支场景
- 多版本共存：推荐按版本后缀隔离配置条目；契约数量少时可单配置多版本，按 mt+版本区分寻址
- 版本路由：请求可指定版本，未指定时按默认版本选取
- 契约被删除：网关索引以配置为准，删除后立即不可达；实例下次发布时同步清理标记
- 实例已下线但契约仍在：契约仍可查，实例列表为空时返回无可用实例错误

## 异常场景 & 业务错误码
| 场景 | 错误码 | 业务表现 |
| ---- | ------ | -------- |
| 配置中心不可用（启动期） | CONFIG_CENTER_UNAVAILABLE | 网关与 Provider 启动失败并明确报错，不允许无契约索引启动 |
| 配置中心不可用（运行期） | -（降级） | 沿用本地索引继续服务，恢复后增量补齐 |
| 契约标识冲突 | CONTRACT_CONFLICT | 发布期聚合索引校验，冲突中断启动 |
| 同版本签名不兼容 | CONTRACT_INCOMPATIBLE | 拒绝发布并中断启动 |
| 并发发布被覆盖 | -（防护） | 按版本号/内容比较，旧内容不得覆盖新内容 |
| 序列化方式声明不一致 | SERIALIZER_MISMATCH | 启动校验失败 |

## 数据约束
- 顺序不变量（关键）：**先发布契约元数据，后注册实例**，任一步失败中断启动
- 元数据字段：契约标识、接口全名、方法名、参数名与类型、返回类型、服务名、版本、标签、序列化方式、schema 引用、契约级超时
- 契约变更经配置推送秒级生效；变更与实例变动互不干扰
- 契约变更、契约误删纳入变更评审；保留版本后缀直到确认下线

## 权限与数据隔离
- 契约配置按服务维度隔离，一个服务一份，互不可写
- 聚合索引支持跨服务契约标识判重

## 并发与重试规则
- 并发发布采用内容比较防旧覆盖新
- 网关索引刷新期间不得出现请求错误尖刺（原子替换）

## 业务容量约束
- 单服务契约数较旧模型（挂实例元数据）大幅放宽，可按服务拆分多份配置
- 网关契约条目按业务规模设上限并监控淘汰

## 验收用例（测试要点）
✅ 正向用例
- 新契约发布后，网关经配置推送秒级可见并可调用
- 契约变更只刷新契约索引，实例变动只刷新地址列表，互不引发全量刷新
- 发布自检日志输出 `meta published` 与 `registry joined`

🔄 边界用例
- 多版本共存时按 mt+版本正确寻址，默认版本回退正确
- 契约删除后立即不可达，实例下次发布同步清理标记
- 空实例结果短时缓存（默认 1 秒）防击穿

❌ 异常用例
- 启动期配置中心不可用：两侧启动失败、报错明确
- 运行期配置中心不可用：沿用本地索引继续服务、恢复后补齐
- 冲突发布、不兼容发布中断启动
- 并发发布时旧内容无法覆盖新内容

## 兼容与灰度规则
- 元数据发布方式可配置回退：配置中心模式 / 实例元数据模式 / 仅日志模式（排障用）
- 网关与 Provider 对同一契约的序列化声明不一致时启动校验失败

## 业务埋点与告警指标
- 契约发布失败、索引刷新失败告警
- 配置推送至索引生效耗时（目标秒级）
- 单服务契约数量监控与超阈值告警

## 规格备注
- 本能力是 v2.0 元数据重构核心：契约明细从每实例一份迁移为每服务一份
- 与 `contract-definition`（条目来源）、`contract-gateway-routing`（索引消费方）关联
