## 能力概述
为后端能力提供统一的契约声明与导出控制：开发者在契约接口方法上声明契约标识（mt），只有同时满足"接口列入导出白名单 + 方法标注契约标识"两个条件，该能力才允许对外暴露；面向后端开发者与架构评审角色。

## 业务前置条件
- 契约接口集中在统一的契约定义模块中，该模块只包含接口、DTO、契约注解，不承载业务实现
- 契约标识只允许标注在接口方法上；实现类为普通 Bean，不承担契约声明职责
- 编译期保留方法参数名（缺失时启动告警）
- 一个白名单接口只允许一个实现参与发布，多实现必须显式指定唯一实现，否则启动失败

## 输入定义
| 名称 | 类型 | 是否必填 | 说明 |
| ---- | ---- | -------- | ---- |
| 契约标识（mt） | 文本 | 是 | 标注于接口方法；格式为`业务域.动作`，全小写、点分层、无中文与空格；全局唯一 |
| 导出白名单 | 资源文件 | 否 | 每行一个接口全限定名，`#`为注释，空行忽略；不提供则不导出任何契约 |
| 契约版本 | 文本 | 否 | 默认 `1.0.0` |
| 实例标签 | 文本列表 | 否 | 如 gray、canary，用于标签路由 |

## 输出定义
| 名称 | 类型 | 说明 |
| ---- | ---- | ---- |
| 契约条目 | 结构化数据 | 对外可调用的能力单位：标识、接口全名、方法名、参数名与类型、返回类型、版本、标签、序列化方式、超时 |
| 发布自检日志 | 结构化日志 | `export loaded` / `contract ready` 记录，作为上线验收依据 |

## 主流程（正向链路）
1. 开发者在契约接口方法上标注唯一契约标识。
2. 将该接口全限定名写入导出白名单文件。
3. 编写实现类并声明为普通 Bean（不写契约注解、不写框架注解）。
4. 应用启动后加载白名单，容器内匹配实现 Bean，提取契约条目并完成唯一性校验。
5. 输出发布自检日志，契约进入可发布状态。

## 分支场景
- 空白名单：不发布契约、不注册对外入口，应用正常启动
- 接口列入白名单但无任何标注方法：接口生效，无契约导出
- 接口列入白名单，仅标注契约标识的方法对外暴露，未标注的方法不导出
- 白名单某行不是接口类型（是类）：整行忽略并告警
- 白名单只影响对外暴露，不影响接口在本应用内部被注入与调用

## 异常场景 & 业务错误码
| 场景 | 错误码 | 业务表现 |
| ---- | ------ | -------- |
| 白名单条目类不存在或加载失败 | EXPORT_LOAD_FAILED | 按快速失败配置决定中断启动（默认中断）或告警跳过 |
| 契约标识重复（同应用或跨服务） | CONTRACT_CONFLICT | 发布校验失败，中断启动 |
| 契约方法存在重载 | CONTRACT_OVERLOAD_FORBIDDEN | 违反契约规范，扫描阶段拒绝并明确报错 |
| 编译期参数名缺失 | PARAM_NAME_MISSING | 启动告警，提示取参失败风险 |
| 实现方法签名与接口不一致 | SIGNATURE_MISMATCH | 跳过该契约并告警 |
| 多实现未指定唯一实现 | IMPL_AMBIGUOUS | 启动失败，提示显式指定 |

## 数据约束
- 契约标识全局唯一，跨服务不可重复；一个接口方法最多一个契约标识
- 契约标识一经发布不得变更，变更视同新契约上线
- 同标识同版本签名必须一致；签名变更（含新增可选参数）属破坏性变更，必须新增版本并保留旧版本直至下线
- 仅返回体新增字段属兼容变更，可沿用同版本
- 契约参数类型限定为可序列化 POJO、基础类型、集合；禁止 Map、内部类、不可控泛型
- 方法可见性为 public、非 static、非 default

## 权限与数据隔离
- 白名单属于应用自身，只读取本应用资源，不做跨 jar 合并
- 白名单是架构级一票否决：未列入的接口不扫描、不发布、对外不可达，任何一侧无法绕过

## 并发与重试规则
- 白名单为静态资源，变更需重新扫描或重启；提供重新扫描管理入口，变更纳入发布流程

## 业务容量约束
- 单契约参数建议不超过 10 个，超过应评估改为 DTO 入参
- 单服务契约数设阈值，超过触发告警并建议拆分服务

## 验收用例（测试要点）
✅ 正向用例
- 三步接入（接口标注 + 白名单 + 实现类）后，契约条目可被完整提取，自检日志包含 `export loaded` 与逐契约 `contract ready`
- 未标注方法、未列入白名单接口均不出现在契约条目中

🔄 边界用例
- 空白名单应用正常启动且不注册对外入口
- 白名单含非接口行、注释行、空行时按规则忽略并告警
- 多实现显式指定唯一实现后正常发布

❌ 异常用例
- 重复契约标识中断启动并给出冲突明细
- 重载方法被扫描拒绝
- 白名单条目类不存在时默认中断启动
- 签名不一致的契约被跳过且不影响其他契约

## 兼容与灰度规则
- 破坏性变更走新版本，旧版本保留直至确认下线
- 新契约先以 JSON 序列化上线验证，再按契约粒度灰度切换二进制

## 业务埋点与告警指标
- 契约发布失败告警
- 白名单解析失败告警
- 单服务契约数量超阈值告警

## 规格备注
- 与 `contract-metadata`（元数据发布）、`contract-provider-invoke`（扫描与调用落地）强关联，本规格约束"什么能导出"，后两者约束"如何发布与调用"
- 方法禁止重载是全链路硬约束，直接影响调用器生成与参数分发
