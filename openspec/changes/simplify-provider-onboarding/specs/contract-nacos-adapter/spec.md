## 能力概述
官方 Nacos 适配模块：将契约元数据发布（配置中心写入）与实例注册/反注册（服务发现）以自动装配形式内置，业务应用仅需依赖该模块并配置注册中心地址，即可在 nacosConfig 正式发布模式下完成接入，无需手写任何桥接代码；面向业务后端开发者与运维角色。

## 业务前置条件
- 应用已按三步接入契约能力（Provider Starter 已引入且总开关开启）
- 具备可达的 Nacos 2.x 服务端（配置中心与服务发现同址）
- 应用为 Web 应用（泛化入口需要容器端口，实例注册需要本地端口）
- 元数据发布模式为配置中心模式（nacosConfig）

## 输入定义
| 名称 | 类型 | 是否必填 | 说明 |
| ---- | ---- | -------- | ---- |
| 注册中心地址 | 配置项 | 是 | Nacos server-addr（如 `127.0.0.1:8848`） |
| 命名空间 | 配置项 | 否 | 默认公共命名空间 |
| 配置分组 | 配置项 | 否 | 默认 `CONTRACT`（契约元数据专用分组） |
| 注册 IP | 配置项 | 否 | 默认自动探测本机地址 |
| 服务名 | 配置项 | 是 | 默认取应用名（即元数据 dataId 与实例注册服务名） |
| 契约版本 | 配置项 | 否 | 默认 `1.0.0` |
| 客户端版本 | 依赖管理 | 否 | 适配模块内置 nacos-client 依赖版本，业务可经依赖管理覆盖 |

## 输出定义
| 名称 | 类型 | 说明 |
| ---- | ---- | ---- |
| 元数据写入器 | 框架组件 | 按 `{服务名}-contract-meta`、`CONTRACT` 分组发布契约元数据（供 Starter 内置编排调用） |
| 实例注册桥 | 框架组件 | 元数据发布成功后注册实例（携带契约版本与契约数量极简标记）；应用关闭时自动反注册 |
| 适配自检日志 | 结构化日志 | 适配装配结果（地址/命名空间/分组）与降级原因明示 |

## 主流程（正向链路）
1. 业务应用依赖官方 Nacos 适配模块。
2. 配置注册中心地址与应用名。
3. 启动应用：适配模块自动装配元数据写入器与实例注册桥；内置启动编排先发布元数据、发布成功后注册实例。
4. 自检日志四段齐全（export loaded / contract ready / meta published / registry joined）。
5. 应用关闭：实例自动反注册，网关侧实例列表随之更新，无残留实例。

## 分支场景
- 未配置注册中心地址：适配不装配并告警，元数据发布回退仅日志模式（logOnly），应用正常启动
- 未引入适配模块：Starter 行为与既有形态一致（logOnly 或业务自备桥接）
- 业务覆盖依赖版本：适配模块随业务依赖管理的 nacos-client 版本运行，不做版本强绑
- 多实例同服务名发布：沿用既有并发发布防覆盖规则（旧内容不覆盖新内容）

## 异常场景 & 业务错误码
| 场景 | 错误码 | 业务表现 |
| ---- | ------ | -------- |
| Nacos 不可达（启动期） | - | 元数据发布失败，中断启动并给出明确原因（延续发布顺序不变量） |
| 元数据发布成功但实例注册失败 | - | 中断启动，不留"元数据在而实例缺"之外的中间态（实例句柄由容器持有，关闭即清理） |
| 配置分组写入冲突 | - | 按版本/内容比较防覆盖，冲突内容不生效并告警 |
| 运行期 Nacos 断连 | - | 实例心跳由客户端维持/恢复；网关侧沿用最近快照，不清空 |

## 数据约束
- 元数据布局延续既有约束：`group=CONTRACT`、`dataId={服务名}-contract-meta`
- 实例元数据仅极简标记（契约版本、契约数量），不携带契约明细
- 适配模块不创建额外配置、不修改既有 dataId 内容格式

## 权限与数据隔离
- 适配模块仅访问 `CONTRACT` 分组与自身服务名的实例注册，不触碰其他分组/服务
- Nacos 账号权限遵循业务侧最小权限原则

## 并发与重试规则
- 发布与注册为启动期一次性动作，沿用 Starter 内置编排的顺序不变量与失败中断语义
- 反注册随应用关闭执行一次，重复调用幂等（客户端容忍）

## 业务容量约束
- 沿用契约元数据容量约束（按服务拆分配置、单服务契约数阈值告警）

## 验收用例（测试要点）
✅ 正向用例
- 依赖适配模块 + 配置地址，nacosConfig 模式零桥接代码完成发布与注册，自检四段齐全
- 应用关闭后 Nacos 无残留实例（反注册生效）
- 网关订阅到该服务契约并可 `?mt=` 调用成功（端到端）

🔄 边界用例
- 未配置地址：回退 logOnly 并告警，应用正常启动
- 业务覆盖 nacos-client 版本后适配正常运行
- 非配置中心发布模式（logOnly）：适配不参与发布，不影响启动

❌ 异常用例
- Nacos 不可达：中断启动且错误信息明确
- 实例注册失败：中断启动，无中间态残留

## 兼容与灰度规则
- 适配模块为可选依赖：不引入时既有接入形态（logOnly / 业务自备桥接）完全不变
- 手写桥接（旧形态）与适配模块并存时以业务自备组件优先（可替换语义），日志明示

## 业务埋点与告警指标
- 适配装配/降级日志（缺地址、组件被业务覆盖）
- 元数据发布与实例注册成功/失败日志（关联自检四段）
- Nacos 客户端连接异常告警

## 规格备注
- 本能力与 `contract-starter-access`（内置编排调用方）、`contract-metadata`（发布布局与不变量）强关联：本能力只承载"官方桥接"，发布语义与顺序不变量由前两者定义
- 适配模块不依赖 spring-cloud-alibaba：使用原生 nacos-client，保持版本由业务统一管理的既有决策
